# Engramu
Engramu is an intelligent and neuroscience-backed learrning platform to enable learning in the most effective way possible. Rules are enforced on both teachers and students, which results into best learning environment.

---

### HLD:
![HLD](Assets\hld.png)

There will be two roles, Teacher and Student but Student can also create mini courses using AI.

Main services would include Authentication Service, AI Service (for creating course and helping student learn more effeciently) and aggresive Cache for saving AI calls.

### Complete Tech Stack:

1. Language: TypeScript
2. Frontend: React, Tailwind CSS
3. Backend: Node.js, Express
4. Database: MongoDB/PostgreSQL

1. 80/20 Rule Implementation

5. Practice Sheet

7. Spaced Repitition
